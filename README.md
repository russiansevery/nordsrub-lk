# Личный кабинет клиента «Русский Север»

Веб-кабинет, где клиент видит ход строительства своего дома. Данные берутся из Битрикс24 по входящему вебхуку; клиенту Битрикс нигде не показывается.

Сейчас готово (шаг 1):

- вход по email и паролю, временный пароль и обязательная смена при первом входе;
- приглашение клиента кнопкой из сделки (бизнес-процесс «Открыть личный кабинет»);
- главная: карточка объекта, фасад, текущий этап и диаграмма Ганта по этапам;
- переключатель объектов, если у клиента несколько сделок;
- демо-режим без Битрикса.

Чат, фото, документы, камера и материалы пока заглушки.

## Стек

Next.js 15 (App Router), React 19, TypeScript, PostgreSQL (драйвер `pg`, без ORM), nodemailer, vitest.

## Запуск на сервере

Нужны Node.js 20+ и PostgreSQL 14+.

```bash
npm ci
cp .env.example .env      # заполнить, см. ниже
npm run db:migrate        # создать таблицы
npm run build
npm start                 # порт 3000, перед ним nginx с HTTPS на lk.nordsrub.ru
```

Сборка standalone: можно запускать `node .next/standalone/server.js`, скопировав рядом `public` и `.next/static`.

### Переменные `.env`

| Переменная | Что это |
|---|---|
| `APP_URL` | Адрес кабинета, например `https://lk.nordsrub.ru` |
| `DATABASE_URL` | Подключение к PostgreSQL |
| `BITRIX_WEBHOOK_URL` | Отдельный входящий вебхук Битрикс24 для кабинета (права crm, disk, user, im, task). Пусто = демо-режим |
| `INVITE_SECRET` | Секрет для кнопки приглашения: `openssl rand -hex 24` |
| `SMTP_URL`, `MAIL_FROM` | Почта для писем с паролем |

Секреты хранятся только в `.env` на сервере или в GitHub Secrets. В репозиторий и в чаты их не кладём.

## Показ без Битрикса и базы

Если в `.env` пусты и `BITRIX_WEBHOOK_URL`, и `DATABASE_URL`, кабинет запускается без базы: вход под одним демо-аккаунтом (`DEMO_EMAIL` / `DEMO_PASSWORD`, по умолчанию demo@nordsrub.ru / demo2026), данные тестового объекта.

```bash
npm ci && npm run build && npm start
```

## Приглашение клиента из Битрикса

В воронке «Проекты» создать бизнес-процесс «Открыть личный кабинет» с действием «Исходящий вебхук» (или «Запрос HTTP»):

```
https://lk.nordsrub.ru/api/bitrix/invite?deal={{ID}}&token=<INVITE_SECRET>
```

Кабинет берёт email из контакта сделки, создаёт клиента (или привязывает новую сделку к существующему), отправляет письмо с временным паролем и пишет результат комментарием в ленту сделки.

## Этапы

Стадии сделки сопоставляются с 11 этапами для клиента (`src/lib/project/stages.ts`) по названию. Проверить сопоставление на живом Битриксе:

```bash
npm run bitrix:stages
```

Если какая-то стадия попала не туда, добавьте её в `BITRIX_STAGE_MAP`.

## Разработка

```bash
npm install
npm run db:migrate
npm run client:create -- demo@nordsrub.ru demo-pass-123   # тестовый клиент
npm run dev
```

Без `BITRIX_WEBHOOK_URL` кабинет показывает демо-объект. Проверки: `npm run typecheck`, `npm test`.
